CHRISTIAN PEREZ PORTFOLIO
========================

Files:
- index.html: The complete portfolio website. The profile image is embedded in the HTML.

How to open:
1. Extract this ZIP file.
2. Open the christian_perez_portfolio folder.
3. Double-click index.html to open it in a browser.

Features:
- Black-and-white responsive design
- Animated dropdown navigation and section transitions
- Editable portfolio text
- Skills and definitions
- Photo/video gallery with a 50 MB per-file limit
- Browser-local media persistence using IndexedDB

Note:
Uploaded gallery files are saved in the browser's local storage for the same browser/profile. They are not uploaded to a public server or synced across devices. Clearing browser site data can remove saved gallery items.
